🌲 2. Manipulacion del DOM

2.1 ¿Que es el DOM?

El DOM(document object model) es la representación en forma de arbol del HTML Javascrip puede leer y modificar ese arbol en tiempo real.

Metodos clave para Seleccionar elementos:

  • docuemnt.getElementById("id")
  • document.querySelector(".clase")= El primero que coincida.
  • document.querySelectorAll(".clase")= todos (NodeList)

2.2 Modificar contenido y Estilos

                            
const titulo = document.querySelector("#MiTitulo");
//Cambiar texto 
titulo.textContent = Nuevo Titulo
titulo.innerHTML = <em>Con HTML</em>

//Cambiar Estilos
titulo.style.color = #4321ee

//Añadir o Quitar clases
titulo.classListadd("destacado");
titulo.classListremove("destacado");

3. Event Listener

3.1 ¿Que es un evento?

Un eventoes una acción que ocurre dentro del navegador: un click, una tecla, un envio de formulario, un scroll, etc. los Listener son funciones que reaacionan a esos eventos.

                        
elemento.addEventListener(click,()=>{
    console.log(¡Hiciste click!);
});

3.2 Eventos mas usados

click

Click del usuariio sobre el elemento.

Input

Se dispara cada vez que el usuario le escribe.

Change

Cuando el valor de un campo cambia y pierde foco.

Submit

Envio de un formulario

Keydown/ Keyup

Cuando se presiona o se suelta una tecla

Mouseover / Mouseout

Cuando el cursor entra o sale de un elemento.

5. Introduccion a Jquery

5.1 ¿Que es Jquery?

Jquery es una libreria de Javascript creada coin el fin de simplidicar la manipulñacion del DOM(Document Object Model), el manejo de eventos y las peticiones AJAX. Aunque hoy existen alternativas modernas( React o VueJS), entender JQuery sigue siendo util por su presencia en proyectos.

Su lema: "Write less, do more"(Escribe menos, haz mas).

5.2 JavaScript vs JQuery: Comparacion

Seleccionar un elemento por id:

                        
//Javascript puro
const el= document.getElementById("miId");

//JQuery
const el = $("#miId");

Añadir un evento click: 

                        
//Javascript puro
document.getElementById("btn").addEventListener("click", ()=>{
    alert("HolClasea");
});


//JQuery
$("#btn").on("click", ()=>{
    alert"Hola"
});

Cambiar el texto de varios elementos:

                        
//Javascrip puro
document.querySelectorAll("".item").forEach(el => el.textContent = "X");
//JQuery
$(.item).text("X");
