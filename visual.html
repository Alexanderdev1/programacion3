Propiedad Display

Descripcion

La propuedad Displayespecifica el tipo de cuadro de representacion utilziado para un elemento. Es uan de las propiedades de CSS mas importanmtes para el control del diseño.

Valores Comúnes

  • block: El elemento genera un cuadro de bloque, ocupando todo el ancho disponible
  • inline: El eleemnto genera uno o mas cuadros en linea que no generan saltos de linea
  • inline-block: Similar a inline pero permite establecer width y heigth
  • flex: Establece un contenedor flexible
  • grid: Establece un contenedor de cuadricula
  • none: Oculta completamente el elemento

Ejemplo de codigo

                                
.elemento{
    display:block;
}

.menu{
    display: flex;
    justify-content: space-between;
}

.oculto{
    display:none;
}

Propuedades postion

Descripcion

La propuedad position especifica el metodo de posicionamiento par un elemento. Los elementos posicionados se colocan usando las propiedades top,right, bottom y left.

Valores comunes

  • static: valor por defecto, sigue el fluje nomal del documento.
  • relative: se posiciona relativo a su posicion normal.
  • absolute: se posiciona relativo al ancestro mas cercano posicionado como mas cercano
  • fixed: se posiciona relativo a la ventana del navegador.
  • sticky: alterna entre relative y fexed basado en el scroll

Ejemplo de codigo

                                
.relativo{
    position: relative;
    top: 20px;
    left: 30px;
}

.fijo{
    position: fixed;
    bottom: 0;
    right: 0;
}


.absoluto{
    position: absolute;
    bottom: 0;
    right: 0;
}

Box Model

Descripcion

El Box Model(modelo de caja) es fundamental en CSS, cada elemento es representado como una caja rectangular con las siguientes partes: contenido, padding, border y margin.

Propiedades relacionadas

  • width: Ancho del contenido
  • heigth: Alto del contenido
  • padding: Espacio entre el contenido y el borde
  • border: Borde alrededor del padding y el contenido
  • margin: Espacio exterior, fuera del borde
  • box-sizing: Cmabia como se calculan width y height

Ejemplo de codigo

                                    
.caja{
   width: 200px;
   height: 100px;
   padding: 20px;
   border: 5px solid #4361ee;
   margin: 30px; 
}

/*Border-box incluye padding y border en el width/heigth*/
.caja-inteligente{
    box-sizing: border-box;
    width: 200px;
    padding: 20px;
}

Flexbox

Descripcion

Flexbox es un modelo de un layout unidimensional para direccionar el espacio entre elementos y alinearlos de manera eficiente.

Propiedades principales

  • display: flex: Convierte un contenedor en flex
  • flex-direction: Direccion de los elementos. (row, column)
  • justify-content: Alineacion al eje principal
  • align-items: Alineacion al eje cruzado
  • flex-wrap:Controla si los elementos deben tener wrap
  • gap:Espacio entre elementos.

Ejemplo de codigo

                            
.contenedor-flex{
    display: flex;
    flex-direction: row;
    justify-content: space-between;
    align-items: center;
    gap: 10px;
}

.elemento-flex{
    flex:1; /*Ocupacion de espacio disponible*/
}

Grid

Descripcion

CSS Grid es un sistema de layout bidimensional que permite crear diseños complejos mediante la definicion de filas y coluimnas. Es ideal para estructuras generelaes de pagina

Propiedades principales

  • display: grid: Convierte un contenedor en grid
  • grid-template-columns: Define las columnas de grid
  • grid-template-rows: Define las filas del grid
  • gap: Espacio entre elementos
  • grid-area:Especifica ubicacion y tamaño de un elemento
  • grid-template-areas:Define un templete con nombres

Ejemplo de codigo

                            
.contenedor-grid{
    display: grid;
    grid-template-columns: 1fr 2fr 1fr;
    grid-template-rows: 100px auto 100px;
    gap: 15px;
}

.cabezera{
    grid-column:1/4; /*Ocupa desde la columna 1 hasta la 4*/
}

Transform

Descripción

La propiedad transform permite modificar visualmente un elemento mediante rotación, escala, inclinación o traslación. Estas transformaciones no afectan el layout alrededor del elemento.

Funciones Comúnes

  • translate(): Mueve el elemento en el plano.
  • rotate(): Rota el elemento (grados, radianes).
  • scale(): Escala el elemento (aumenta/disminuye tamaño).
  • skew(): Inclina el elemento.
  • matrix(): Combina todas las transformaciones.

Ejemplo de Código

                    
.rotar {
    transform: rotate(45deg);
}

.escalar {
    transform: scale(1.2);
}

.mover {
    transform: translate(50px, 20px);
}

.combinar {
    transform: rotate(20deg) scale(1.1);
}

Animaciones

Descripción

Las animaciones en CSS permiten crear transiciones y animaciones entre estilos sin necesidad de JavaScript. Se definen mediante reglas keyframes que especifican los estados de la animacion

Propiedades Comunes

  • animation-name: Nombre de la animación(@Keyframes)
  • animation-duration: Duración de la animación.
  • animation-timing-function: Funcion de temporización.
  • animation-delay: Retraso antes de comenzar.
  • animation-iteration-count: Número de repeticiones.
  • animation-direction: Dirección de la animación.

Ejemplo de Código

                                
/*Definir la animación*/
@keyframes ehenoki{
    0% { opacity: 0; }
    100% { opacity:1; }
}

/*Aplicar la animacion*/
.elemento{
    animation-name: ejemplo;
    animation-duration: 2s;
    animation-timing-function: ease-in-out;
    animation-iteration-count: infinite;
}

/*Forma abreviada*/
.elemento-corto{
    animation: ejemplo 2s ease-in-out infinite;
}
